# Curso Completo de Engenharia de Software — Ementa

Estrutura: **Núcleo (20 módulos)** + **Trilhas de especialização** + **Projeto contínuo**.
Cada módulo tem ~10 aulas (10–20 min), com objetivo, teoria curta, exercício prático e checklist.

## Projeto contínuo
O aluno constrói um mesmo sistema (ex.: plataforma de tarefas/e-commerce) que evolui a cada módulo:
CLI → API → banco → frontend → testes → CI/CD → cloud → observabilidade → segurança.

---

## PARTE 1 — Fundamentos (iniciante)

### Módulo 1 — Fundamentos da Computação
Bits/bytes, CPU, memória, armazenamento, sistemas operacionais, processos e threads, compilação vs interpretação, como a internet funciona.

### Módulo 2 — Terminal, Linux e Ambiente de Desenvolvimento
Shell, permissões, pipes, scripts Bash, editores/IDEs, gerenciadores de pacotes, variáveis de ambiente.

### Módulo 3 — Lógica e Programação (Python)
Variáveis, tipos, condicionais, loops, funções, módulos, arquivos, exceções, depuração, ambientes virtuais.

### Módulo 4 — Matemática e Lógica para Computação
Lógica booleana, conjuntos, combinatória, probabilidade básica, álgebra linear essencial, bases numéricas, grafos (conceito).

### Módulo 5 — Estruturas de Dados
Arrays, listas ligadas, pilhas, filas, hash tables, árvores, heaps, grafos, tries.

### Módulo 6 — Algoritmos e Complexidade
Big-O, busca, ordenação, recursão, divisão e conquista, programação dinâmica, greedy, algoritmos em grafos, resolução de problemas.

### Módulo 7 — Git, GitHub e Colaboração
Git interno, branches, merge/rebase, PRs, code review, fluxos (trunk-based, GitFlow), issues, projetos, open source.

---

## PARTE 2 — Construção de Software (intermediário)

### Módulo 8 — Paradigmas, POO e Clean Code
POO (4 pilares), composição vs herança, programação funcional, SOLID, nomes, funções pequenas, code smells, refatoração.

### Módulo 9 — Segunda Linguagem e Tipagem (TypeScript/Java/Go)
Tipagem estática, generics, gerenciamento de memória, comparação entre linguagens, quando usar cada uma.

### Módulo 10 — Banco de Dados Relacional e SQL
Modelagem (ER), normalização, SQL completo, joins, índices, transações, ACID, migrations, otimização de queries.

### Módulo 11 — Bancos NoSQL e Armazenamento de Dados
Documento, chave-valor, colunar, grafo, busca (Elasticsearch), teorema CAP, quando escolher cada um, ORMs.

### Módulo 12 — Redes e Protocolos
TCP/IP, DNS, HTTP/1.1/2/3, TLS, WebSockets, CDN, proxies, load balancers.

### Módulo 13 — Backend e APIs
REST, GraphQL, gRPC, autenticação/autorização (JWT, OAuth2, OIDC), validação, versionamento, documentação (OpenAPI), paginação, idempotência.

### Módulo 14 — Frontend Moderno
HTML/CSS/JS avançado, acessibilidade, React (ou similar), estado, roteamento, performance web, SSR/SSG, design responsivo, noções de UX.

### Módulo 15 — Testes e Qualidade
Pirâmide de testes, unitários, integração, E2E, TDD/BDD, mocks, cobertura, testes de contrato, testes de carga, mutation testing.

---

## PARTE 3 — Engenharia em Escala (avançado)

### Módulo 16 — Arquitetura de Software e Padrões de Projeto
Padrões GoF, arquitetura em camadas, hexagonal, DDD, monolito modular vs microsserviços, event-driven, CQRS, ADRs.

### Módulo 17 — Design de Sistemas e Sistemas Distribuídos
Escalabilidade, cache, filas/mensageria (Kafka/RabbitMQ), consistência, replicação, sharding, consenso, concorrência, resiliência (retry, circuit breaker), cases reais.

### Módulo 18 — DevOps, CI/CD e Containers
Docker, Kubernetes, pipelines CI/CD, GitHub Actions, estratégias de deploy (blue/green, canary), feature flags, Infraestrutura como Código (Terraform).

### Módulo 19 — Cloud, Observabilidade e SRE
AWS/Azure/GCP essenciais, serverless, logs/métricas/tracing, SLI/SLO, incident response, post-mortems, FinOps.

### Módulo 20 — Segurança de Software
OWASP Top 10, criptografia, gestão de segredos, threat modeling, SAST/DAST, supply chain, LGPD/privacidade, DevSecOps.

---

## PARTE 4 — Profissão

### Módulo 21 — Processos, Requisitos e Gestão
Agile, Scrum, Kanban, levantamento de requisitos, user stories, estimativas, métricas (DORA), documentação, gestão de dívida técnica.

### Módulo 22 — IA no Desenvolvimento de Software
Copilot e assistentes, engenharia de prompts, revisão de código gerado, agentes, integração de LLMs em apps (RAG, APIs), limites e ética.

### Módulo 23 — Carreira, Comunicação e Soft Skills
Comunicação técnica, trabalho em equipe, liderança técnica, mentoria, portfólio, currículo, LinkedIn, entrevistas técnicas e comportamentais, negociação, ética profissional.

### Módulo 24 — Projeto Final (Capstone)
Planejar, construir, testar, fazer deploy e apresentar um sistema completo com documentação, CI/CD e monitoramento.

---

## Trilhas de Especialização (opcionais, 3–4 módulos cada)
- **Frontend Avançado**: design systems, performance, state management, testes visuais.
- **Backend Avançado**: microsserviços, event sourcing, alta performance, Java/Go/.NET.
- **Cloud & DevOps**: Kubernetes avançado, Terraform, plataformas internas, certificações.
- **Dados & IA**: engenharia de dados, pipelines, ML básico, MLOps, LLMs.
- **Mobile**: Android/iOS, React Native/Flutter, publicação em lojas.
- **Segurança Ofensiva/Defensiva**: pentest, AppSec, resposta a incidentes.
- **Jogos**: engines, física, gráficos.

## Totais
24 módulos × ~10 aulas ≈ **240 aulas** no núcleo, mais as trilhas opcionais.
