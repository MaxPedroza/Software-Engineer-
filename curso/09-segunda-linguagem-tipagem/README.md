# Módulo 9 — Segunda Linguagem e Tipagem (TypeScript)

**Nível:** Intermediário · **Pré-requisitos:** Módulo 8
**Objetivo:** aprender uma linguagem estaticamente tipada e comparar paradigmas e ecossistemas.

## Aulas
1. Por que aprender mais de uma linguagem
2. Tipagem estática vs dinâmica, forte vs fraca
3. TypeScript: tipos básicos e inferência
4. Interfaces, types e enums
5. Generics
6. Módulos, npm e tooling (tsconfig, linters, formatadores)
7. Programação assíncrona (callbacks, Promises, async/await)
8. Gerenciamento de memória e garbage collection
9. Comparando linguagens (Python, TypeScript, Java, Go) e quando usar cada uma
10. Revisão e quiz do módulo

## Projeto contínuo
Reescrever o núcleo do sistema de tarefas em TypeScript com tipos estritos.

## Entregável
Biblioteca TypeScript tipada e publicada localmente via npm link.
