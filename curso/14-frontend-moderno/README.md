# Módulo 14 — Frontend Moderno

**Nível:** Intermediário · **Pré-requisitos:** Módulos 9 e 13
**Objetivo:** construir interfaces acessíveis, rápidas e bem estruturadas.

## Aulas
1. HTML semântico e acessibilidade
2. CSS: layout, Flexbox e Grid
3. Design responsivo e fundamentos de UX/UI
4. JavaScript no navegador e DOM
5. React: componentes, props e estado
6. Hooks, efeitos e gerenciamento de estado
7. Roteamento e consumo de APIs
8. SSR, SSG e frameworks (Next.js)
9. Performance web (Core Web Vitals) e PWA
10. Revisão e quiz do módulo

## Projeto contínuo
Interface web do sistema de tarefas consumindo a API do Módulo 13.

## Entregável
Aplicação React responsiva, acessível e com nota alta no Lighthouse.
