# Módulo 18 — DevOps, CI/CD e Containers

**Nível:** Avançado · **Pré-requisitos:** Módulos 7 e 15
**Objetivo:** automatizar build, teste e entrega de software.

## Aulas
1. Cultura DevOps e ciclo de entrega
2. Docker: imagens, containers e Dockerfile
3. Docker Compose e redes de containers
4. Integração contínua com GitHub Actions
5. Entrega e implantação contínuas (CD)
6. Estratégias de deploy: rolling, blue/green e canary
7. Feature flags e gerenciamento de configuração
8. Kubernetes: conceitos essenciais
9. Infraestrutura como Código (Terraform)
10. Revisão e quiz do módulo

## Projeto contínuo
Pipeline que roda testes, gera imagem Docker e faz deploy automático.

## Entregável
Pipeline CI/CD completo versionado no repositório.
