# Módulo 7 — Git, GitHub e Colaboração

**Nível:** Iniciante/Intermediário · **Pré-requisitos:** Módulo 2
**Objetivo:** trabalhar em equipe com controle de versão e revisão de código.

## Aulas
1. Por que controle de versão
2. Git básico: init, add, commit, log, diff
3. Branches e merge
4. Rebase, cherry-pick e resolução de conflitos
5. Remotos, push, pull e fork
6. Pull Requests e code review
7. Fluxos de trabalho (trunk-based, GitFlow)
8. Issues, Projects e boas mensagens de commit
9. Contribuindo para open source
10. Revisão e quiz do módulo

## Projeto contínuo
Publicar o projeto no GitHub, usar branches por funcionalidade e abrir PRs revisados.

## Entregável
Repositório com histórico limpo, PRs e issues organizados.
