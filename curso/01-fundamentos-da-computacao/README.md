# Módulo 1 — Fundamentos da Computação

**Nível:** Iniciante · **Pré-requisitos:** nenhum
**Objetivo:** entender como um computador funciona por dentro, para que o resto do curso faça sentido.

## Aulas
1. O que é Engenharia de Software e o que faz um engenheiro
2. Bits, bytes e representação de dados (binário, hexadecimal, ASCII/Unicode)
3. CPU, memória RAM e armazenamento
4. Sistemas operacionais: o que são e para que servem
5. Processos e threads
6. Sistema de arquivos
7. Compiladores vs interpretadores
8. Como um programa é executado (do código ao processador)
9. Como a internet funciona (visão geral: cliente, servidor, IP, DNS)
10. Revisão e quiz do módulo

## Projeto contínuo
Definir a ideia do sistema que será construído ao longo do curso e escrever uma descrição de 1 página.

## Entregável
Documento curto: "Como um programa chega do código ao processador" com diagrama próprio.
