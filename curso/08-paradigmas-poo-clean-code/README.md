# Módulo 8 — Paradigmas, POO e Clean Code

**Nível:** Intermediário · **Pré-requisitos:** Módulos 3 e 7
**Objetivo:** escrever código legível, coeso e fácil de manter.

## Aulas
1. Paradigmas de programação
2. Orientação a objetos: classes, objetos, encapsulamento
3. Herança, polimorfismo e abstração
4. Composição vs herança
5. Programação funcional (imutabilidade, funções puras, map/filter/reduce)
6. Princípios SOLID
7. Clean Code: nomes, funções e comentários
8. Code smells e refatoração
9. Tratamento de erros e design by contract
10. Revisão e quiz do módulo

## Projeto contínuo
Refatorar a CLI de tarefas para classes bem definidas aplicando SOLID.

## Entregável
Código refatorado com explicação de cada decisão de design.
