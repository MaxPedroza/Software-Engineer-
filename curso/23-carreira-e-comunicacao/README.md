# Módulo 23 — Carreira, Comunicação e Soft Skills

**Nível:** Todos · **Pré-requisitos:** nenhum
**Objetivo:** desenvolver as habilidades não técnicas que definem a progressão na carreira.

## Aulas
1. Níveis de carreira (júnior a staff) e trilhas (IC vs gestão)
2. Comunicação técnica escrita e oral
3. Trabalho em equipe e feedback
4. Gestão de tempo e aprendizado contínuo
5. Liderança técnica e mentoria
6. Portfólio, GitHub e currículo
7. LinkedIn, networking e marca pessoal
8. Entrevistas técnicas e de system design
9. Entrevistas comportamentais, negociação e ética profissional
10. Revisão e quiz do módulo

## Projeto contínuo
Montar portfólio com o projeto do curso, README profissional e apresentação.

## Entregável
Currículo, perfil e portfólio publicados.
