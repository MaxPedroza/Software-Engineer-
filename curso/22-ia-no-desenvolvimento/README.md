# Módulo 22 — IA no Desenvolvimento de Software

**Nível:** Avançado · **Pré-requisitos:** Módulos 8 e 15
**Objetivo:** usar IA com critério para aumentar produtividade sem perder qualidade.

## Aulas
1. Como funcionam os LLMs (visão prática)
2. Assistentes de código (GitHub Copilot e similares)
3. Engenharia de prompts para desenvolvimento
4. Revisão crítica de código gerado por IA
5. Testes, documentação e refatoração com IA
6. Agentes de código e fluxos automatizados
7. Integrando LLMs em aplicações (APIs, streaming)
8. RAG, embeddings e bancos vetoriais
9. Riscos: alucinações, segurança, licenças e ética
10. Revisão e quiz do módulo

## Projeto contínuo
Adicionar ao sistema um recurso com LLM (ex.: resumo e sugestão de tarefas) com guardrails.

## Entregável
Funcionalidade com IA, testes de avaliação e documento de riscos.
