# Módulo 2 — Terminal, Linux e Ambiente de Desenvolvimento

**Nível:** Iniciante · **Pré-requisitos:** Módulo 1
**Objetivo:** dominar o terminal e montar um ambiente de desenvolvimento profissional.

## Aulas
1. Por que aprender o terminal
2. Navegação e manipulação de arquivos (ls, cd, cp, mv, rm)
3. Leitura e busca em texto (cat, less, grep, find)
4. Pipes, redirecionamento e composição de comandos
5. Permissões, usuários e variáveis de ambiente
6. Gerenciadores de pacotes (apt, brew, winget)
7. Scripts Bash: variáveis, condicionais e loops
8. Editores e IDEs (VS Code, atalhos, extensões)
9. Containers de desenvolvimento e WSL
10. Revisão e quiz do módulo

## Projeto contínuo
Criar o repositório do projeto, a estrutura de pastas e um script `setup.sh` que prepara o ambiente.

## Entregável
Script Bash que automatiza a configuração do ambiente.
