# Módulo 3 — Lógica e Programação (Python)

**Nível:** Iniciante · **Pré-requisitos:** Módulo 2
**Objetivo:** escrever programas completos usando os conceitos fundamentais de programação.

## Aulas
1. Primeiro programa e como pensar como um programador
2. Variáveis, tipos e operadores
3. Condicionais
4. Laços de repetição
5. Funções e escopo
6. Listas, tuplas, dicionários e conjuntos
7. Módulos, pacotes e ambientes virtuais
8. Leitura e escrita de arquivos (texto, JSON, CSV)
9. Exceções e depuração
10. Revisão e quiz do módulo

## Projeto contínuo
CLI de gerenciamento de tarefas (adicionar, listar, concluir, remover) salvando em arquivo JSON.

## Entregável
Aplicação CLI funcional com tratamento de erros.
