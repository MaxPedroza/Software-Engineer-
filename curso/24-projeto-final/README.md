# Módulo 24 — Projeto Final (Capstone)

**Nível:** Avançado · **Pré-requisitos:** Módulos 1–23 (ou trilha equivalente)
**Objetivo:** consolidar todo o aprendizado em um sistema completo, pronto para produção.

## Etapas (aulas)
1. Definição de escopo, requisitos e backlog
2. Arquitetura e ADRs
3. Modelagem de dados e contratos de API
4. Implementação do backend
5. Implementação do frontend
6. Testes automatizados e qualidade
7. CI/CD e deploy em cloud
8. Observabilidade, segurança e revisão final
9. Documentação e demo
10. Apresentação final e retrospectiva

## Critérios de avaliação
- Funcionalidade e qualidade do código
- Cobertura de testes e pipeline CI/CD
- Arquitetura documentada
- Segurança e observabilidade
- Documentação e apresentação

## Entregável
Sistema em produção, repositório organizado e apresentação gravada.
