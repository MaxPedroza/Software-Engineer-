# Módulo 21 — Processos, Requisitos e Gestão

**Nível:** Avançado · **Pré-requisitos:** Módulo 7
**Objetivo:** entender como equipes planejam e entregam software.

## Aulas
1. Ciclo de vida de software (cascata, iterativo, ágil)
2. Scrum e Kanban
3. Levantamento e análise de requisitos
4. User stories e critérios de aceite
5. Estimativas e planejamento
6. Métricas de engenharia (DORA, lead time)
7. Gestão de dívida técnica
8. Documentação técnica e RFCs
9. Gestão de produto, priorização e MVP
10. Revisão e quiz do módulo

## Projeto contínuo
Criar backlog, roadmap e RFC para uma nova funcionalidade do sistema.

## Entregável
Backlog priorizado com user stories e critérios de aceite.
