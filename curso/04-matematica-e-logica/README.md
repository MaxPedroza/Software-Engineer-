# Módulo 4 — Matemática e Lógica para Computação

**Nível:** Iniciante · **Pré-requisitos:** Módulo 3
**Objetivo:** adquirir a base matemática necessária para algoritmos, bancos de dados e criptografia.

## Aulas
1. Lógica proposicional e álgebra booleana
2. Tabelas-verdade e simplificação de expressões
3. Conjuntos e relações
4. Funções e notação matemática
5. Análise combinatória
6. Probabilidade e estatística básica
7. Sistemas de numeração e aritmética binária
8. Álgebra linear essencial (vetores e matrizes)
9. Introdução a grafos
10. Revisão e quiz do módulo

## Projeto contínuo
Implementar em Python um avaliador de expressões booleanas e uma calculadora de conversão de bases.

## Entregável
Biblioteca pequena de utilitários matemáticos com testes simples.
