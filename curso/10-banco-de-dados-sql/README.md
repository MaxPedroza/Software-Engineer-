# Módulo 10 — Banco de Dados Relacional e SQL

**Nível:** Intermediário · **Pré-requisitos:** Módulo 4
**Objetivo:** modelar dados e consultar bancos relacionais com eficiência.

## Aulas
1. Conceitos de bancos de dados e SGBDs
2. Modelagem entidade-relacionamento
3. SQL básico: SELECT, INSERT, UPDATE, DELETE
4. Joins e subconsultas
5. Agregações, GROUP BY e funções de janela
6. Normalização e desnormalização
7. Índices e planos de execução
8. Transações, ACID e níveis de isolamento
9. Migrations, constraints e boas práticas
10. Revisão e quiz do módulo

## Projeto contínuo
Persistir usuários, projetos e tarefas em PostgreSQL com migrations.

## Entregável
Modelo ER, scripts de migration e consultas otimizadas documentadas.
