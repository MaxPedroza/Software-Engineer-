# Módulo 5 — Estruturas de Dados

**Nível:** Iniciante/Intermediário · **Pré-requisitos:** Módulos 3 e 4
**Objetivo:** escolher e implementar a estrutura de dados adequada a cada problema.

## Aulas
1. Por que estruturas de dados importam
2. Arrays e listas dinâmicas
3. Listas ligadas
4. Pilhas e filas
5. Tabelas hash
6. Árvores e árvores binárias de busca
7. Heaps e filas de prioridade
8. Grafos e representações
9. Tries e estruturas especializadas
10. Revisão e quiz do módulo

## Projeto contínuo
Implementar um índice de busca de tarefas usando hash e trie; comparar com busca linear.

## Entregável
Implementações próprias de pilha, fila, hash e BST, com testes.
