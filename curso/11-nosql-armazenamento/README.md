# Módulo 11 — NoSQL e Armazenamento de Dados

**Nível:** Intermediário · **Pré-requisitos:** Módulo 10
**Objetivo:** escolher o armazenamento certo para cada necessidade.

## Aulas
1. Limites do modelo relacional e surgimento do NoSQL
2. Bancos de documentos (MongoDB)
3. Chave-valor e cache (Redis)
4. Bancos colunares e séries temporais
5. Bancos de grafos
6. Busca full-text (Elasticsearch/OpenSearch)
7. Teorema CAP e consistência eventual
8. ORMs e acesso a dados (vantagens e armadilhas)
9. Armazenamento de arquivos e objetos (S3), backups e retenção
10. Revisão e quiz do módulo

## Projeto contínuo
Adicionar cache com Redis e busca full-text às tarefas.

## Entregável
Documento de decisão (ADR) justificando cada tecnologia de armazenamento escolhida.
