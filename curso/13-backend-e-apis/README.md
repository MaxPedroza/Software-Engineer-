# Módulo 13 — Backend e APIs

**Nível:** Intermediário · **Pré-requisitos:** Módulos 9, 10 e 12
**Objetivo:** construir APIs robustas, documentadas e seguras.

## Aulas
1. Arquitetura cliente-servidor e papel do backend
2. Design de APIs REST
3. Validação, serialização e tratamento de erros
4. Autenticação e sessões
5. Autorização, JWT, OAuth2 e OIDC
6. Paginação, filtros, versionamento e idempotência
7. Documentação com OpenAPI/Swagger
8. GraphQL e gRPC
9. Jobs em background, filas e webhooks
10. Revisão e quiz do módulo

## Projeto contínuo
API REST completa das tarefas com login, autorização por usuário e documentação OpenAPI.

## Entregável
API publicada localmente com coleção de requisições e documentação.
